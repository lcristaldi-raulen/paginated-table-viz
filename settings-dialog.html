Leave a name blank to keep Tableau's field name. Hide blanks the header cell for that column — the column and its data stay, only the heading text goes, which is what you want under a merged band that already names the group.

Merged bands

Give columns the same band name to merge them into one heading spanning those columns. Only adjacent columns merge, so two runs with the same name stay separate.
No column list available — open this dialog from the ⚙ button on a sheet that already has fields on the Columns shelf. You can still edit the mapping by hand below as {"Field Name": "BAND"}.
A band spanning Week 1–7 also shows the full span those columns cover — the earliest start to the latest end, e.g. Jun 20 – Aug 7. Columns with a date label but no band name group into a range band of their own, so you can get this without naming anything.
Columns with no band name take the full height of both header tiers, so their heading uses the whole block instead of sitting under an empty strip. Untick to give every column a band cell, empty or not. This applies to the PDF as well as the view.
On, such a heading sits at the top of the merged block, level with the band names beside it. Off, it follows the Header vertical setting below like every other heading.
On, a band is exactly as wide as the columns beneath it and a long name is trimmed to fit. Off, a long band name can stretch those columns wider than the widths you set for them.
Instead of trimming a name that will not fit, break it across lines and grow the band row to suit. The columns underneath keep the widths you set.
A vertical rule down the full height of the table wherever one band ends and the next begins. Works even with the band row itself hidden. Tick Div beside any column on the Table tab to add a line to the left of that column too.

Date labels

Puts “Aug 1–7” under a “Week 1” header, with the dates coming from the parameter below.
The report's through-date. Labels recompute automatically whenever this parameter changes — nothing to retype.
Every column whose header starts with this and ends in a number gets a label, and that number decides which period it is — so reordering columns can't scramble the dates.
No column list available — open this dialog from the ⚙ button on a sheet that already has fields on the Columns shelf. You can still edit the mapping by hand below as {"Field Name": period}.
Tick the columns that represent a time period and give each its period number. 1 is the period defined by “Week 1 is” above; 2 is one step earlier, and 0 or negative numbers run the other way — handy for a “next week” column.
Tick All instead to show the overall span of every dated column under that header — a Total Change column reading 6/28–8/8 while the period columns beside it each show their own week. Those columns keep their own name.
Untick to drop the number — every period column then reads just “Week”, with the date range underneath telling them apart.
A labelled column's first line becomes this, with {n} replaced by its period number — so a CN Comp Days column set to period 3 reads “Week 3” over “Jul 18–24”. Anything you type into Header overrides above still wins.

Page setup

On, the sizes on the Type tab drive the PDF as well as the view — pixels become points at 0.75, so 12px on screen prints at 9pt, and changing one changes both. The two sliders below are then ignored. Off, the PDF keeps its own absolute sizes and the Type tab affects only the view. Either way, per-column, band and group sizes keep their relative emphasis, and the fit settings shrink everything to size if it will not fit the paper.
Matching means a printed page carries exactly the rows one on-screen page carries, so the PDF and the view line up row for row. Choose the other option to pack each sheet full instead, which uses less paper but no longer mirrors the view.
On (recommended), the table is laid out once, measured, and if it runs past the right margin the whole thing — type, padding and every column width — is scaled down by exactly the overflow so it lands inside the page. The scale used is reported in the toast. Off, wide tables spill off the edge of the paper.
Legal landscape is the default and fits roughly twice the columns of Letter portrait. Tabloid is wider again if you need it. Wrap long text in every column and Max wrapped lines on the Table tab both apply here: with wrapping off, a column that does not fit is cut with an ellipsis on paper just as it is on screen.

Conditional formatting

Rules run top to bottom over the cell values and stack, so a later rule can override an earlier one. Numbers are read from the underlying value, falling back to the displayed text with currency symbols, thousands separators, percent signs and accounting-style parentheses handled. Dates compare chronologically.
Compare to field tests a cell against another column in the same row — that's how you flag a date that has slipped past its scheduled counterpart.
No rules yet — every cell uses the plain body style.
